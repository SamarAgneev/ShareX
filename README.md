A simple AI Image Generator web application that creates images from text prompts using an image generation API.  
This project is beginner-friendly and open for contributions.

---

## Live Demo

https://deepaktecz.github.io/AI-Image-Generator/

---

## Features

- Generate images using text prompts
- Multiple image generation support
- Model selection
- Image ratio selection
- Responsive gallery grid
- Light/Dark mode toggle

## Tech Stack

- HTML
- CSS
- JavaScript
- AI Image Generation API
